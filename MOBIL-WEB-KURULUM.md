# KASA PRO V19 - Mobil Web

Bu paket telefon/tablet tarayıcıları için responsive web ve PWA desteği içerir.

## Vercel
- Framework: Vite
- Build: npm run build
- Output: dist
- Environment Variables:
  - VITE_SUPABASE_URL
  - VITE_SUPABASE_PUBLISHABLE_KEY

## Telefonda kullanım
Vercel adresini telefonda Chrome/Safari ile açın. Desteklenen cihazlarda "Ana ekrana ekle" ile uygulama gibi kullanılabilir.
