
# Supabase V19 tek seferlik kurulum

Supabase SQL Editor → New query bölümünde `SUPABASE_1_SEFER_FINAL_GUVENLI.sql` dosyasının tamamını bir kez çalıştırın.

Bu kurulum dosyası mevcut iş verilerini silen DROP/TRUNCATE komutları içermez. Uygulamanın kullandığı uyumluluk RPC katmanını ve bildirim/kapsam/işlem/fatura yönetimi için gereken fonksiyonları tanımlar.
