# KASA PRO — Dünya Genelinde Web Erişimi

Bu proje Vite + React + Supabase tabanlıdır ve statik web olarak yayınlanabilir. `vercel.json` SPA yönlendirmesini içerir.

## Yayın
1. Projeyi GitHub/GitLab hesabınıza yükleyin.
2. Vercel üzerinde projeyi içe aktarın.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Environment variables: `.env.example` içindeki Supabase değişkenlerini Vercel Project Settings > Environment Variables bölümüne ekleyin.
6. Deploy sonrası verilen `https://...vercel.app` adresinden dünyanın her yerinden giriş yapılabilir.

Not: Bu kaynak paketi web yayınlamaya hazırlar; gerçek alan adı/hosting hesabına dağıtım için kullanıcının hosting hesabına bağlanması gerekir.
